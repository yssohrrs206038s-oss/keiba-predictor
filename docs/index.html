KEIBA EDGE について

KEIBA EDGEは機械学習（XGBoost）とClaude AIを組み合わせた重賞予想システムです。

過去の出走データ・騎手成績・コース適性・馬場状態・脚質など47の特徴量を学習した独自モデルで3着以内確率を算出。期待値（EV）スコアにより「オッズと確率のギャップ」がある馬を発見します。

モデル精度AUC 0.8638は競馬予想AIとして高水準（ランダム予測は0.5）。1万回のモンテカルロシミュレーションで安定軸・展開依存馬を判定し、SHAP値で予測根拠を可視化します。
